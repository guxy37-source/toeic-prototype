# 拾分 · TOEIC 学习平台

本地优先的英语学习平台：完整题库、整套模拟考试、Part 专项练习、错题复习、语境词卡与能力画像。原生 HTML / CSS / JavaScript，无前端构建依赖。

## 开始使用

完整媒体通过 **Git LFS** 存储。克隆时需要 Git LFS，否则音频和图片会是文本指针，不能播放或显示。

```sh
git lfs install
git clone https://github.com/guxy37-source/toeic-prototype.git
cd toeic-prototype
git lfs pull
npm test
npm start
```

Node.js 20 或更高版本；无需 npm install。访问 http://127.0.0.1:4173。可用环境变量 `PORT` 更改端口。也可用浏览器直接打开 `index.html`，或由 Nginx 等静态服务器托管整个目录。

## 功能

- **模拟考试**：整套 200 题；听力、阅读分段计时；答题卡、检查标记、保存进度、自动交卷。
- **分题型练习**：Part 1–7，可限时或不限时。
- **错题复习**：错题与未作答题进入复习队列，支持收藏、错因、笔记和简化间隔计划。
- **听力精练**：材料去重、变速和循环播放；原文与解析关联。
- **语境词卡**：保留词语、释义、例句与来源题目。
- **总览评估**：听读模拟参考分、题型能力画像、样本覆盖与评估依据。
- **成绩报告**：正确率、分 Part 表现、整套托业模拟参考分及参考区间。

## 题库与媒体

31 套、6,200 道题，引用媒体 4,840 个，约 1.1 GB。`assets-manifest.json` 包含文件路径、大小和 SHA-256。

- `exam-data.js`：完整试题、正确答案、材料路径与原解析。
- `audio/`、`images/`：通过 Git LFS 管理的媒体。
- `data.js`：公开版本的空学习记录种子。

**公开版本不包含作者的个人作答、笔记、收藏或浏览器历史。** 首次打开时错题列表与能力评分为空，完成考试后建立自己的记录。本地原版本不受此仓库初始化影响。

## 数据保存

账号、服务器数据库、跨设备同步尚未接入。新增作答、考试历史、笔记和复习计划存储在当前浏览器 localStorage，清除浏览器数据会清除这些记录。可在“关于这个原型”中导出 JSON 备份；当前没有备份导回界面。

保持相同访问地址以继续使用原浏览器记录；切换端口、域名或本地文件路径可能使用不同的存储空间。

## 评分边界

参考 [IIBC 公开模考换算表（第 3 页）](https://www.iibc-global.org/hubfs/library/default/toeic/special/job/u-trial202303/pdf/utrial_score.pdf?hsLang=ja)，分别换算听力和阅读参考区间，采用区间中点作为单值显示，总分使用 10–990 分制。该表原本用于特定试卷，应用到本题库仅为近似参考，不是官方等值换算或经过校准的预测。

总览依据跨试卷的去重加权作答；整套模考报告依据该次实际答对数。发音、词汇无专项测量时显示待评估；语法、构文等级仅作相关题型参考。

## 已知题库问题

ABCEED 模考题-07 Q29，以及模考题-08 Q29 / Q30 的原音频关联有疑点。当前保持原关联，并在考试前和题内提示；尚未自动修改。

## 项目结构

```text
index.html          页面入口
app.js / style.css  学习与复习界面
exam.js             模拟考试与报告
ability.js          能力画像与证据统计
toeic-score.js      模考参考分换算
data.js             空学习记录种子
exam-data.js        完整题库
audio/ images/      Git LFS 媒体
scripts/serve.cjs   本地静态服务器，支持音频 Range 请求
tests/validate.cjs  数据、媒体、隐私字段与换算检查
```

这是单人学习平台原型；部署到 `/opt/apps/toeic-ai` 的服务端整合尚未执行。服务器账号、数据库持久化和 AI 接口需后续另行接入。
